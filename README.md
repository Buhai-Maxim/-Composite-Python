# Патерн Composite

Це невеликий приклад до курсової роботи з патернів проєктування. За основу взято файлову систему, тому що вона складається з папок і файлів.

## Ідея

Файл є простим елементом, а папка може містити багато інших елементів. При цьому і файл, і папка мають однакові методи `show()` та `get_size()`.

У програмі використані такі класи:

- `Component` — базовий клас;
- `File` — окремий файл, тобто Leaf;
- `Folder` — папка, тобто Composite.

Метод `get_size()` у файлу просто повертає його розмір. У папки цей метод проходить по всіх елементах усередині та додає їхні розміри.

## Запуск

```text
python composite_project.py
```

Програма виведе дерево папок і файлів та порахує загальний розмір файлів.

## Висновок

Composite зручно використовувати тоді, коли об'єкти утворюють дерево. Клієнтський код може працювати і з одним файлом, і з цілою папкою однаково. Такий підхід можна використати не тільки для файлової системи, а й для меню, каталогів товарів або структури організації.
